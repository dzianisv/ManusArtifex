## INCIDENT: servo stall (2026-07-28 13:11)
- Symptom: gripper finger made loud grinding/straining noise; human switched arm power OFF.
- Trigger: agent ran chained `robohand pose open_grip` → `pose --save` → `pose close_grip` → `pose home`. `close_grip` drove GRIP (servo 1) against its mechanical end stop on empty air → locked-rotor stall.
- Root cause: no per-servo safe limits, no stall detection, no torque-off on failure-to-reach. Full 500..2500 range assumed safe — it is NOT.
- Fix required before any motion: conservative per-joint limits, partial-close gripper definition, read-back stall guard that RELAXES the servo instead of holding torque, global watchdog, relax-on-SIGINT.
- **Rule: never command a LeArm servo to a hard limit; never hold torque on a servo that failed to reach target.**

## Robo Hand SDK hardening — outcome (2026-07-28)
- ROOT CAUSE of stall: LeArm gripper (servo 1) valid range is **1500..2500**, NOT 500..2500. Reference lib: `case LeArm: if(servo==1) return clamp(value,1500,2500)`. Lower raw = MORE OPEN; 1500 is the open stop. The pose `close_grip=700` was 800 below the floor → drove past the stop → splayed jaws + locked-rotor grinding (matches operator video).
- Position feedback is PHYSICALLY IMPOSSIBLE (PWM servos, no data line). cmd 21 can never reply. Camera is the only real feedback.
- Fix: three-layer defence — (1) per-servo absolute bounds + calibration gate, (2) time-bounded torque w/ auto-unload + watchdog + unload on exit/SIGINT/exception, (3) vision frame-diff stall detection. Motion requires a single-use MotionToken bound to the transport, so no code path can bypass the safety layer.
- Simulator (`robohand/sim.py`) models mechanical end stops; 30/30 pytest green. Counterfactual proven: unguarded GRIP=700 → 600ms stall; guarded → refused, 0ms.
- `reset_arm.py` = emergency stop (ACTION_GROUP_STOP + unload). Commands no motion, safe any time.
- `pushButtons.py` disabled (commanded ELBOW 2600, past the 2500 max).
