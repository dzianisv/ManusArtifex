
## Robo Hand — hardware discovery (2026-07-28)
- Arm: Hiwonder/LewanSoul LeArm / xArm 1S, 6 servos, LSC-6 controller. **USB HID 0483:5750**, product_string `LOBOT`, mfr `MyUSB_HID`. NOT a serial device — no /dev/cu.usb*.
- Driver: fork https://github.com/dzianisv/xArmServoController → `cd Python && pip install -e .`. Upstream ccourson repo has no packaging (pip install from git subdirectory FAILS).
- `xarm.Controller('USB').getBatteryVoltage()` → 7.396 V (works). `getPosition(i)` → IndexError in `_recv` (short/empty HID report) — upstream bug.
- Servo map (pushButtons.py): 1=GRIP 2=WRIST_ROLL 3=WRIST_FLEX 4=ELBOW 5=SHOULDER_LIFT 6=SHOULDER_PAN; raw 500..2500, center 1500.
- Only one process may hold the HID handle at a time.
- Protocol ground truth: `doc/LSC Series Servo Controller Communication Protocol V1.2.pdf`.
- Camera: only built-in FaceTime HD detected; faces the user, not the workspace.
- Notion: project page "Robo Hand", child pages `backlog` and `spec` (spec = command log).
